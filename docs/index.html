Services

Five things we do. One of them most of the time.

Core service

Python & Django development

Web applications, REST APIs, and internal tools with Python, Django, and PostgreSQL or SQLite. Anything from a single CRUD form to a full back office with imports, reports, and role-based access. Upgrades and rescue work on existing Django codebases welcome. Python is the preferred stack, not the only one: development and maintenance in C, C++, Java, Go, and PHP as well.

Training

Oracle Tuxedo training for developers and administrators, based on the Packt book Modernizing Oracle Tuxedo Applications with Python. A TigerBeetle course is in preparation.

Server administration

Linux servers set up and maintained: hardening, updates, backups, and someone to call when a disk fills up. Every server we run is watched by microsre.io, our own local-first monitoring tool. Docker and Kubernetes when the project calls for them, a plain well-kept VPS when it does not.

Data collection & analysis

Public web data gathered on a schedule, cleaned, and delivered as a database, spreadsheet, report, or API. Prices, public registries, competitor pages: collected and kept fresh without anyone clicking around.

3D printing & prototyping

A workshop running several 3D printers, including a custom machine we designed and built ourselves. Custom weather stations, small toys, and branded merchandise for organizations: keychains, tags, and similar giveaway items. Devices designed, printed, and programmed to do one job and report back to your systems.

The engineering behind Teogro

Teogro is a small company, and the work behind it is not. Two decades of building systems where a rounding error is a bug and a duplicate transfer is an incident.

  • Payment and ledger systemsCard issuing and authorization, SEPA and SWIFT payments, ISO 20022 migration, 3-D Secure, PCI-DSS compliance.
  • Legacy modernizationIncremental migration of Oracle Tuxedo estates to modern stacks. Author of the Packt book Modernizing Oracle Tuxedo Applications with Python.
  • Performance and incidentsRoot cause analysis that goes all the way down: kernel crashes traced to a buggy backup software kernel module, slow virtual machines explained by a host and guest filesystem mismatch, PostgreSQL and application code performance. One such story became the conference talk How to Solve a Python Mystery.
  • Open sourceContributions to Python 3.12 and Django 5.1, plus published projects that show how we build: django-taskq, a Celery-compatible queue on a database backend, distilled from decades of building queues; hisstrace, syscall interception and fault injection in dependency-free pure Python; otelite, an OpenTelemetry backend small enough for a dev container; fuxedo, an open source alternative to Oracle Tuxedo; and tuxedo-python, Python bindings for the original.
  • Conference speakingSREcon26 EMEA on hidden process state in procfs, DjangoCon Europe, PyCon Austria, PostgreSQL Conference Europe. Full list at aivarsk.com/speaking.
